# Modifica chirurgica della bozza

Applica solo il feedback dell'utente.

- Cambia le parti esplicitamente richieste.
- Il resto resta identico, parola per parola: stessa struttura, stesso linguaggio, stessi dettagli.
- Non "migliorare", espandere o condensare sezioni non citate.
- Tocca altro solo se la modifica crea un'incoerenza narrativa inevitabile, e nel minimo indispensabile.
